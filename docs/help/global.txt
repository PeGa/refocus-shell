refocus — tracks where your attention went, without an opinion about it.

  focus <command> [args]

tracking a session
  on [project]    start (no project = continue your last)
  pause           pause — silent, the timer remembers
  continue        resume, carrying elapsed time forward
  off             stop, and leave a note for next time
  status          what's happening right now

history
  past list [n]                          full history, or the last n
  past add <project> <start> <end>       log one with times
  past add <project> --duration 2h       log one by duration
  past modify <id> ...                   fix a session
  past delete <id>                       remove one
  report today|week|month|custom <n>     where the time went
  report cycle [id|-n]                   where a period's time went

periods — a marker for "here starts the new count"
  cycle add                              mark the end of a period
  cycle modify --edit-notes <id>         write what the period was
  cycle modify --edit-time <id> <time>   move a marker (receipts regenerate)
  cycle delete <id>                      remove a marker
  past cycles                            every marker
  past cycles show [id|-n]               what happened in a period

nudging — the periodic reminder; an external clock for time-blindness
  enable          arm it (install already does this)
  disable         silence it (only when no session is open)
  nudge status    is it on? what's scheduled?
  nudge test      fire a test notification

checking in — asks if you forgot to track, only while idle
  checkin status  is it on? what's scheduled?
  checkin test    fire a test popup

setup & data
  config show|set|unset            settings        (focus help config)
  export [name]                    back up to .sql + .json
  import <file>                    restore (leaves tracking off)
  init                             create the database
  reset                            wipe everything (asks for "yes")

  focus help <command>   detail on any of these

idle is a valid state. a long hyperfocus is a valid state.
refocus only makes sure you know which one you're in.
