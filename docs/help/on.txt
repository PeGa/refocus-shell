# focus on — Start a session
# ==========================

USAGE
  focus on [project]

BEHAVIOUR
  No project given
    Offers to continue the last project. Shows total time logged.
    If the user answers No, exits cleanly with a hint.
    If no history exists, requires a project name (exit 2).

  Project given, prior time logged
    Typo guard: "X has Ym logged. Continue? (Y/n)"
    This catches accidental mis-spellings before starting a duplicate ledger.

  Project given, no prior time
    Starts immediately, no prompt.

  While disabled
    Hard stop: run 'focus enable' first. (exit 1)

  While active or paused
    Hard stop: tells you what's running and how to resolve. (exit 1)

NOTES
  - Projects are labels, not stored entities. The name IS the identity.
  - Recommended naming: customer/project-name (git-commit style, no spaces).
  - Max project name length: MAX_PROJECT_LENGTH (default 100 chars).
