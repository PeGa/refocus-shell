focus on — start a session

  focus on [project]

Start tracking. The name is just a label — customer/project reads well in reports.

  no project      offer to continue your last (shows time logged); declining exits clean
  known project   typo guard: "X has Ym logged. Continue? (Y/n)"
  new project     starts right away
  disabled        stops you — run 'focus enable' first
  already busy    stops you — close the open session first

Starting is meant to be one word, or none. Low cost on purpose.
