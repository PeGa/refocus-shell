focus import — restore from a backup

  focus import <file.sql|file.json>

Replaces everything. Warns you if a session is open, backs up the current
database first, and asks you to type "yes".

  .sql    restored exactly
  .json   rebuilt row by row (needs jq; old 'projects' data is ignored)

Afterward, tracking is left off on purpose — 'focus enable' when you're ready.
