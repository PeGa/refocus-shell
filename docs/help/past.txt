# focus past — Manage past sessions
# ===================================

USAGE
  focus past list [n]
  focus past add <project> <start> <end>
  focus past add <project> --duration Xh [--date YYYY/MM/DD]
  focus past modify <id> [project] [start] [end]
  focus past modify <id> [project] [--duration Xh]
  focus past delete <id>

SUBCOMMANDS
  list [n]
    Prints the last n sessions (default: REPORT_LIMIT).
    Columns: ID, Project, Start, End, Duration. Notes shown on next line.

  add <project> <start> <end>
    Adds a session with full timestamps. Duration is computed automatically.
    Prompts for notes after parsing times.

  add <project> --duration Xh [--date YYYY/MM/DD]
    Adds a duration-only session (no timestamps stored).
    Date defaults to today. Duration formats: 1h30m, 2h, 45m.
    Use this for sessions tracked externally, retroactive entries, or
    time blocks where exact timestamps don't matter.

  modify <id> [project] [start] [end]
    Edit a timestamped session. Duration is recomputed from new timestamps.
    Omitted arguments keep their current value.

  modify <id> [project] [--duration Xh]
    Edit a duration-only session. Timestamps cannot be added retroactively.
    Omitting --duration keeps the current duration (rename only).
    Providing timestamps to a duration-only session is an error (exit 2).

  delete <id>
    Prompts for confirmation, then deletes. No undo.

TIME FORMATS
  YYYY/MM/DD-HH:MM   2025/06/11-14:30   (recommended — no quoting needed)
  HH:MM              14:30              (today assumed)
  natural language   'yesterday 14:00'  'two hours ago'

DURATION FORMATS
  1h30m   2h   45m
